HACKATHON PROTOCOLS & MANDATES

RULE PROTOCOL // 01 terminal

FRESH CODEBASE INTEGRITY

All code must be authored inside the official 24-hour sprint window. Pre-existing codebases, uncommitted repos, and pre-packaged applications face instantaneous disqualification. Git commit graphs are checked by scripts.

RULE PROTOCOL // 02 deployed_code

OPEN SOURCE & API POLICIES

Public open-source libraries, open models (HuggingFace/Ollama), and verified external APIs are permitted. All third-party dependencies must be clearly cataloged in the repository README upon submission.

RULE PROTOCOL // 03 groups

SQUAD ENROLLMENT RIGOR

Squads must consist of 2 to 4 validated collegiate students. All participants must present legitimate university student identification cards during on-site physical check-in at Synapse Arena.

RULE PROTOCOL // 04 electrical_services

24/7 POWER & FIBER RUNS

Each squad terminal is provisioned with high-capacity uninterruptible power units and dual Gigabit ethernet ports alongside gigabit campus Wi-Fi. Access to hardware maker labs is free for sensor builds.

RULE PROTOCOL // 05 gavel

CONDUCT & FAIR PLAY DIRECTIVE

Zero tolerance for plagiarism, harassment, or malicious interference with peer terminals. Network telemetry is continuously audited by the festival cybersecurity engineering unit.

RULE PROTOCOL // 06 verified

IP RIGHTS RETENTION

100% intellectual property rights remain in full ownership of the building students. IILM University and sponsoring tech partners claim zero equity or ownership claims over sprint outputs.
